# miniguia-estudos-notebooklm
Projeto de IA Generativa para apoio aos estudos de Python com NotebookLM.
Projeto desenvolvido durante o Bootcamp Bradesco - GenAI, Dados & Cyber da DIO.

## 📖 Sobre

Este projeto consiste na criação de um assistente de estudos utilizando o NotebookLM. Foram adicionados materiais sobre Python para que a IA pudesse responder perguntas, explicar conceitos e auxiliar na aprendizagem de programação.

## 💬 Engenharia de Prompts

### Prompt 1

- Explique listas em Python.

**Resultado:**

A IA me retornou uma resposta bem resumida do assunto, talvez para alguém com certo conhecimento seria ok, mas para alguém que não há nenhum conhecimento talvez não seja o ideal.

### Ajuste do Prompt 1

- Me explique listas em python como se eu fosse um iniciante e não saiba muito do assunto, dar exemplos podem ajudar na compreensão.
 
**Resultado após ajuste:** 

A IA apresentou exemplos comentados, explicou os principais métodos e mostrou situações de uso.


### Prompt 2

- Crie cinco exercícios de dificuldade crescente sobre estruturas de repetição em Python, sem mostrar as respostas.

**Resultado:**

- Foram gerados exercícios organizados do nível básico ao intermediário, permitindo praticar o conteúdo antes de consultar soluções.

### Dificuldades encontradas

- Algumas respostas utilizavam termos técnicos que dificultavam o entendimento. Como solução, refinei os prompts pedindo explicações voltadas para iniciantes e comparações com exemplos do dia a dia.

## 📘 Miniguia de Estudo

### 📝 Resumo

Python é uma linguagem de programação de alto nível, conhecida por sua sintaxe simples e legível. É amplamente utilizada em desenvolvimento web, análise de dados, inteligência artificial, automação de tarefas e desenvolvimento de aplicações.

Os principais conceitos estudados foram:

- Variáveis e tipos de dados;
- Estruturas condicionais (`if`, `elif` e `else`);
- Estruturas de repetição (`for` e `while`);
- Funções;
- Listas, tuplas e dicionários;
- Manipulação de strings;
- Boas práticas de programação.

---

### 📖 Glossário

| Termo       | Significado                                                            |
|-------------|------------------------------------------------------------------------|
| Variável    | Espaço utilizado para armazenar informações na memória.                |
| Lista       | Estrutura que armazena vários elementos e permite alterações.          |
| Tupla       | Coleção semelhante à lista, porém imutável.                            |
| Dicionário  | Estrutura composta por pares chave e valor.                            |
| Função      | Bloco de código reutilizável que executa uma tarefa específica.        |
| Loop        | Estrutura utilizada para repetir instruções.                           | 
| Condicional | Estrutura que permite executar diferentes ações conforme uma condição. |
